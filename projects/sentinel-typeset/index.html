项目实录 / 大洲

Markdown 稿件怎样排成清爽的公众号文章？

在大洲微格把 Markdown 或纯文本放进编辑区，选择主题并实时预览，再复制为公众号富文本。草稿保存在当前浏览器中。

我是这样做的

  1. 导入或粘贴 Markdown、纯文本，检查标题、段落和引用等结构。
  2. 切换主题，在手机预览里调整字号、行距等阅读细节。
  3. 复制排版结果到公众号草稿箱，发布前逐段检查图片和样式。

公开成果与验证

工具已在官网微格页面开放，使用教程、主题库和常见问题也可直接查看。

使用前要知道

草稿保存在本机浏览器，当前没有跨设备同步。页面预览不等于公众号草稿箱验收，更不等于文章已经发布。
