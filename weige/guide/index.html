公众号排版教程：3 分钟搞定

公众号排版最大的内耗是：微信编辑器没有像样的样式系统，标题要手动加粗、引用要手动调色、代码块一粘贴就变形。 这篇教程给你一条最快路径——用大洲微格，3 分钟从 Markdown 到合规排版。

  1. 1

    准备一篇 Markdown 母稿

    用任何你顺手的编辑器（Typora、Obsidian、VS Code、Notion 都行）把文章写成 Markdown。标题用 #/##/###，列表用 -，引用用 >，代码块用三个反引号。Markdown 的好处是：只管内容，不用管样式。

    💡 没有 Markdown 母稿？直接粘贴纯文本或 Word 内容也行，大洲微格会自动识别标题、章节、要点。

  2. 2

    打开大洲微格，粘贴、选主题

    访问 dazhouweige.top/weige/，把 Markdown 粘贴进左侧编辑区。右侧实时预览。从 7 套主题里挑一套适合你文章气质的：教程类选摸鱼绿，深度分析选红白色系，设计观点选石墨极简，科技内容选哨兵深色。

    💡 每套主题都预置了标题、引用、代码块、表格、关键词下划线的完整样式，不用自己调任何参数。

  3. 3

    一键复制合规 HTML

    点「复制 HTML」。大洲微格直接构造微信平台红线合规的富文本：无 div、无 class、无外部样式、全内联样式，粘贴到公众号编辑器不会变形。

    💡 如果想微调，配色实验室可以生成专属配色，固定结尾可以一键带上你的公众号引导。

  4. 4

    去公众号粘贴、发布

    打开公众号后台新建图文，在编辑器里 Ctrl+V / Cmd+V 粘贴，样式完整保留。配好封面图，发布即可。全程 3 分钟。

    💡 粘贴后建议先预览一遍：标题层级、图片、代码块是否都正常。

微信排版红线规则避坑清单

为什么排版会乱？90% 是踩了下面这几条微信红线。记住了，自己手排也不容易翻车：

不要用 div 和 class

微信编辑器只认 span 标签和内联样式，div/class 会被过滤导致整篇乱码。大洲微格输出的是纯 span + 内联样式，天然合规。

不要用外部 CSS

微信不加载外部样式表，任何靠 class 的样式都会失效。所有样式必须内联写在标签上。

禁用 fixed/float/@media

这些 CSS 特性在微信里会被忽略，粘贴后可能出现布局错乱。大洲微格的排版引擎全程规避。

全角标点归一

中英文混排时标点容易混用，排版引擎会自动把标点归一，避免「，」和「,」混出现。
